Бот, написанный на Python 3.12, оповещает о новых 
сообщениях вместе с их контентом из заданных пользователем 
чатах с функцией публикации в целевые чаты данных сообщений.

Команды телеграмм-бота

Запуск/Главное меню:

/start

```
"Новый канал"
```

Запускает интерактивный режим с текстовым вводом необходимых параметров:

- Задание логина исходного канала

- Задание канала публикации

- Инструкция в openAI для изменения поста



```
"Список каналов"
```

Выводит в виде списка:

- Исходный каонал - имя канала, откуда переносим сообщения в бот,

- Канал назначения - имя канала, куда переносим сообщения,

- Текущая инструкция - инструкция к тексту сообщений



Ограничения и выявленные недостатки:

1) Сгруппированные в один пост сообщения (когда у всех одинаковый `media_group_id`) 
отправляются в бот без кнопок меню по причине ограничений telegram api. 
Мы можем их видеть в боте, но не можем их отправить в целевой чат с помощью 
кнопки "Опубликовать". Возможно, в будущем это исправят.

2) Одиночные сообщения с прикреплёнными к ним файлами не отправляются, если 
размер файлов более 50 Мб по причине ограничений telegram api. Но мы условились,
что таких сообщений в наших случаях не будет. Иначе, можно дополнительно написать 
утилиту, которая будет сжимать файлы.

3) Некоторые одиночные сообщения не могут быть отправлены, так как не имеют никаких
атрибутов, которые определяют их как тип сообщения - в зависимости от типа их содержимого.
Хотя, эти сообщения в чатах и выглядят как текстовые, но при этом их атрибут `media` или 
`text` со значением None. Для этого логгер выводит информацию об этом.

4) Telegram api не понимает и то, каким был исходный текст (жирный, перечёркнутый) - 
передаёт стиль по умолчанию.

Что нужно доработать:

1) Добавить вызовы openai, чтобы он изменял текст, в тех сообщениях, где он есть.

2) Чтобы ошибки ввода от пользователя, также перенаправлялись ему в чат бота, 
что он неправильно вводит имя каналов.
